🏠 PG Life – PG Accommodation Discovery Website

A frontend web development project designed to help students discover affordable and comfortable Paying Guest (PG) accommodations in major Indian cities.

📌 About the Project

PG Life is a web-based accommodation discovery platform developed using HTML, CSS and JavaScript.

The project focuses on providing users with an easy-to-understand interface to explore PG accommodation options, view property details and discover suitable places to stay.

✨ Project Highlights

- Student-focused PG accommodation website.
- Property listing interface.
- Property details pages.
- Dashboard page.
- City-focused accommodation discovery.
- Organized HTML, CSS, JavaScript and image assets.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
